# PandaPet

Небольшой локальный питомец-помощник для Windows 11. Панда появляется из-за правого края экрана, располагается над панелью задач, обращается к ребёнку по имени, показывает напоминания и следит за активным временем в выбранных играх.

## Запуск для разработки

```powershell
dotnet run --project .\src\PandaPet\PandaPet.csproj
```

Готовую тестовую сборку можно запустить из `dist\PandaPet.exe`. Для неё требуется установленный .NET 8 Desktop Runtime.

Установка для текущего пользователя:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Install-PandaPet.ps1
```

Установленная версия появляется в меню «Пуск», на рабочем столе и в списке установленных приложений Windows.

Версия проекта хранится централизованно в `Directory.Build.props`. Правила SemVer, выпусков и Git-тегов описаны в `VERSIONING.md`, изменения — в `CHANGELOG.md`.

## Где хранятся настройки

Настройки остаются локально в `%LOCALAPPDATA%\PandaPet\settings.json`.

## Уже реализовано

- мастер первого запуска с обязательным именем ребёнка;
- появление панды справа внизу над панелью задач;
- плавный выход из-за правого края и спокойная idle-анимация;
- напоминание о рюкзаке после 20:00 только по воскресеньям–четвергам;
- ежедневное напоминание о чистке зубов в 21:30;
- кнопки «Готово» и «Через 5 минут»;
- звёзды за выполненные дела;
- отслеживание активного игрового процесса, дневного лимита и настраиваемых периодических перерывов;
- автоматическая проверка перерыва: две минуты вне игры; если ребёнок продолжает играть ещё минуту после напоминания, панда грустит до настоящего перерыва;
- Steam, Minecraft и Roblox в начальном списке игровых процессов;
- одиночный щелчок запускает случайную анимацию и одну из 100 реплик: 60 добрых шуток и 40 полезных микро-подсказок;
- четыре набора по 16 промежуточных поз: поворот головы, подъём обеих лап, двойное подмигивание и дружеское махание одной лапой;
- единый базовый кадр и непрерывная idle-анимация устраняют скачок масштаба; позы меняются без прозрачного смешивания и двойных контуров;
- все позы выровнены по ступням и общей базовой линии, поэтому во время жестов корпус закреплён по центру и не смещается горизонтально;
- спокойная поза и кадры с лапами имеют одинаковые габариты силуэта; программное уменьшение во время жестов отключено;
- в версии 1.3.0 темп жестов и idle-анимации дополнительно ускорен на 10%, чтобы движения оставались плавными, но ощущались живее;
- собственная иконка приложения, встроенная в EXE и ярлыки Windows;
- двойной щелчок сворачивает панду за правый край, а оставшаяся кнопка возвращает её;
- родительские настройки защищены четырёхзначным PIN;
- локальное хранение данных без камеры, микрофона и облака.
